# ✦ 拾页 · RP 世界书与预设管理器

**把故事留住，把整理交给工具。**

拾页（Shiye）是一款为 AI RP 用户设计的轻量级档案管理工具。

无论是长期经营一个复杂的 RP 世界，还是同时游玩多个不同的世界观，拾页都希望让剧情记录、世界设定和对话预设变得更加轻松。

它采用卡片式剧情管理方式，配合内置 AI 整理 Prompt，让你不必每次切换聊天窗口时，都从头手动整理冗长的剧情总结。

## ✨ 核心功能

### 1. 多世界观独立管理
- 创建多个独立的 RP 世界观档案。
- 支持档案切换、重命名和删除。
- 每个档案拥有独立的世界书、剧情时间线、待办事项和预设。
- 不同世界的剧情资料互不混淆。

### 2. 卡片式剧情管理
- 将 AI 整理的剧情拆分成独立事件卡片。
- 每条事件记录时间、标题、起因、经过和结果。
- 支持逐条编辑、审核、删除及批量审核。
- 将近期事件归档至长期时间线。
- 支持手动调整事件顺序，保留模糊时间，不强行编造日期。

### 3. AI 剧情快速更新
内置专用剧情整理 Prompt。

使用方式：
1. 将 Prompt 发送给旧聊天窗口的 AI。
2. 让 AI 整理当前窗口新增剧情，并输出规定格式的 JSON。
3. 将结果粘贴到拾页。
4. 自动生成待审核事件卡片。
5. 检查、修改并审核通过，正式收录到世界书。

同时支持提取尚未解决的矛盾，以及尚未实现的计划与约定。

### 4. 世界书与 RP 预设
**世界书：**
- 时间与历法
- 地点
- 世界设定
- 长期时间线
- 最近事件
- 待审核事件
- 待办事项

**RP 预设：**
- 语气 / 基调
- 文风
- 叙述视角
- 回复结构
- 格式要求
- 禁忌 / 限制
- 特殊响应

### 5. 数据备份与恢复
- 支持单个世界观 JSON 导入与导出。
- 支持多个世界观的集合备份与整体恢复。
- 支持导出 Markdown 阅读版。

## 使用说明

- 无需注册账号，不需要连接 AI API。
- 拾页不会自动读取聊天记录，需要用户手动复制 AI 整理结果并导入。
- 档案数据默认保存在当前浏览器本地。
- 更换浏览器或设备前，请导出 JSON 备份。
- 支持电脑及手机屏幕布局。
